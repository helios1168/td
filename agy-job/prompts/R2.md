## Required CLI and propagation

Add these exact parser arguments to `build_argparser`:

```text
--stage2-reservation {none,uniform,claims}   default none
--reservation-gamma FLOAT                    default 0.60
--reservation-epsilon FLOAT                  default 0.05
```

Use the existing `td.stage2_state.compute_reservation_vector` API and accepted units:

- `S_book = cells.S.sum(axis=(1, 2))`, in `cells.reps` order.
- `region_M = cells.M.sum()` and `region_T = cells.S.sum()` over the complete state-by-channel
  region and candidate roster.
- `T = cells.S.sum(axis=0)` and the ambient cell value
  `c2*T + c_free*cells.S_free + lam*cells.M`, using `model.coefficients(args.theta, args.lam,
  args.filler_capture)`.
- For a `stage2_state.Plan`, compute each used slot's ambient `G0_j` by summing its bundle's
  ambient cells over each state's share `y`; `G0_floor = min_j G0_j`, or zero for an empty plan.
- For `uniform` or `claims`, compute `d_floor = args.reservation_gamma * G0_floor` and call
  `compute_reservation_vector` with the three CLI values. Pass the returned vector and exact
  `reservation_floor=d_floor` to R1's `state_stage2`, together with
  `reservation_mode=args.stage2_reservation`.
- For `none`, pass `reservation=None` and preserve the R1 legacy path. Do not invent a second
  valuation or reservation grain. R1 records `reservation_grain="state"`.

Implement a small typed helper if useful, for example a function that takes `cells`, a
`stage2_state.Plan`, and the parsed arguments and returns `(reservation, d_floor)`. It must be
deterministic, use only state shares, handle an empty used-slot set, and not mutate `cells` or
the plan. Reuse it for every state-stage-2 call.

Thread the selected mode through all current stage-2 calls in `tools/full_plan.py`, including the
base and trial scores in `_rep_moves`, and the final staffing call. A claims reservation must be
computed for the plan being scored, not silently reused after a trial changes the slots. Keep
the existing level-0 solver, bands, prior, projections, and ZIP realization unchanged. Do not
add terminal rematch logic here.

Record the three CLI arguments in `params.json`. The final `staffing.json` must retain all old
keys and carry R1's `reservation_mode`, `reservation_grain`, `clipped_edges`,
`nonpositive_edges`, `hall_shortfall`, and `epsilon_floor` keys. Default `none` must preserve
the legacy assignment, gains, value, and geometry; the added metadata is the only allowed output
shape change.

Reject invalid gamma or epsilon through R1's `compute_reservation_vector` validation. Do not
clip forbidden centered edges, alter candidacy, release reps, or claim that reservations prove
FEFx.
