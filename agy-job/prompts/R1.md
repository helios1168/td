## Required implementation

Add the typed public helper with this API and units:

```python
def compute_reservation_vector(
    S_book: np.ndarray,            # shape (R,), cells.reps order, gain units
    *, region_M: float,            # M(Region), gain units
    region_T: float,               # sum over reps of S_book, gain units
    G0_floor: float,               # min_j G0_j, ambient gain units
    mode: str = "none",            # "none" | "uniform" | "claims"
    gamma: float = 0.60,
    epsilon: float = 0.05,
) -> np.ndarray                    # shape (R,), d_i in gain units
```

Use exactly these accepted definitions:

- `d_floor = gamma * G0_floor`.
- `mode="none"`: every `d_i` is zero.
- `mode="uniform"`: every `d_i` is `d_floor`.
- `mode="claims"`: `alpha = min(1, region_M / region_T) * (1 - epsilon)` when both region
  quantities are positive, and `alpha = 0` when `region_M == 0` or `region_T == 0`; then
  `d_i = alpha * S_book[i] + d_floor`.
- `gamma` is in `[0, 1)`, `epsilon` is in `[0, 1)`, and mode is one of the three names.
- Reject wrong dimensionality, negative gain quantities, non-finite values, and out-of-range
  parameters with `ValueError`. Avoid division by zero for an empty or zero-claim region.
- Reject non-finite resulting reservations as well. Return a fresh float array and do not mutate
  the input.

Extend `state_gain_matrix` and `state_stage2` with an optional keyword `reservation` aligned to
the active rep rows. `None` must preserve the current legacy gain matrix, matching, output values,
and behavior. For a supplied vector:

- Validate it is one-dimensional, finite, nonnegative, and has one entry per active rep row.

  clipping it.

  computed from centered surpluses using the selected criterion. For `criterion="nash"`, every
