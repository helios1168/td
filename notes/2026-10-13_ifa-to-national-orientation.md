## 1. IFA pipeline (as run on `m5-studio/ifa-conus`)

All run folders live under `runs/exp/<lane>/…` (contig lane, per `docs/CODE_MAP.md`), each with `manifest.json` (T1); specs live in `runs/exp/contig/_specs/`.

1. **`tools/exp/contig/run.py <spec> --out <dir> --extract <p> --states <ST> --delta 0.15 --time-limit S [--maps] [--jobs N]`** — master plan + `draw.py` draw on the polygon graph *induced on the states* (`induced_graph`, run.py:149, `--states` run.py:570, scouts branch; M1 still audited on the full graph). Spec copies per state have `k` per state, `margin = false`, `delta/final_delta = 0.15`, `max_size = 1`.
2. **`tools/exp/contig/coarse.py --state NY --k 5 --level sldu|cd [--thin-floor]`** (ifa-midatl only) — ZCTAs → TIGER legislative units → connected components → K connected districts, min border, band `--lo/--hi` (defaults 798.74/1148.19 m_rel, E2) `--window` makes it exact.
3. **`tools/exp/contig/repair.py <run> --states <ST> --window LO,HI --time-limit --neck-time-limit --budget S [--keep-support --flow] [--open-units …] [--jobs N] [--h0 3 --max-zctas 1500]`** — hop-doubling windows (pieces, then necks); `--window` clips every channel's final band to a fixed dollar window (scouts repair.py:1095–1101); `--open-units` is #122's arm-2 split.
4. **`tools/exp/contig/merge.py <merge-spec> ST1=<run> … --out --extract-out [--window 798.74,1148.19] [--gap-width] [--export]`** — merges disjoint state ledgers, re-gates on the full graph, sets k = #merged districts, frees states split across sources, window check "in/under/over" (E2), headline M1 from `TD_NECK_GAP_WIDTH=1` (G3). Built regions (e.g. `ifa/midatl/merged_v2` = NJ+PA+NY folders), then six regions → `ifa/conus/ifa_conus_v2` (scenario `52_ifa_38bcd2d`), `--window 798.74,1148.19 --gap-width --export`.
5. **Exports**: `export_long.py` (nationwide long CSV + `scenarios.csv` tie-back, no dollars/shares/names), `export_geojson.py` (district-reach + states GeoJSON, `Preferences.tps`); images via `tools/maps/render.py`; gate `tools/mandates/check.py`, score `tools/looks/score.py`, shortlist by hand.

`merge.py`/`--states`/`--window`/`coarse.py` exist **only on branches**, not main.

## 2. Formulation as implemented

- **Master MILP** `td/master.py::build` (131–190): n_S ∈ ℤ≥0 (≤1 if a support holds a unit whole, 148–150), t_{v,S} ∈ [0,1]; rows `count` Σ_S n_S = K_c (151), `cover` = 1 (153), η_c·n_S ≤ t ≤ n_S (160–161), `hold` t = n_S (163), **band** (L+μ_S)n_S ≤ Σ M_v t_{v,S} ≤ (U−μ_S)n_S (165–166), `eta_cap` ⌊1/η⌋ (168), contact caps (172), **corridor floor** at cut vertices (177–179), border cap (183), count cap (186), `ban` n_S = 0 (189). Objective Σ w_S n_S, w_S = support diameter (148–50). Smallest δ: `exact_delta` (437, whole/clipped), `bisect_delta` (514, free units). Split handling is the modes (`whole/clipped/free`, decoded Claim 1); μ_S off per channel with `margin = false`.
- **Realizer** `td/realize.py`: centres (139), transport LP (155), forest rounding (203), one repair pass (314), piece causes (347). The pipeline's realizer is `tools/exp/contig/draw.py` (746 `_solve_group`): x_{z,j}, y_{v,j}, one owner per ZCTA, x ≤ y, mass in [τ(1±δ)], exact connectivity via solve-check-cut separators; objective: splits first (`SPLIT_WEIGHT` 1000, line 71), then #121 border term (`border_km` 191), moment tie-break; `NeckCut` (120).
- **M1 neck gate** `td/audit.py`: `NeckGraph` (474), `NECK_W_KM` 10 km / `NECK_SHARE` 5% (`NECK_W_CM`, 444–449), `land_would_do` (531), `district_necks` (565), `check_m1` (800). Gap width: prototype on scouts/ifa branches (env `TD_NECK_GAP_WIDTH` = "1", audit.py ~888): same-state Voronoi-adjacent pairs that are neither polygon edges nor connectors become neck edges as wide as their shared Voronoi border; **`m5-studio/131`** instead builds true gap land (`td/geo.py`:1251–1360, `python -m td geo --gap-land` → `zcta_gap_land.csv.gz`) read default-**on** through `polygon["gaps"]`, opt-out `TD_NECK_GAP_WIDTH=0`; its `tests/test_neck_gapwidth.py` is **stale** (still tests the old sails `voronoi_gaps`, default-off API).

## 3. IFA vs main channel

- **Specs**: `scenarios/50_ifa.toml` (one planning channel IFA over all 49 units, k 50, 27 free states, fine channel `ifa`) vs `scenarios/51_total_13n_11wh_24fi_3wifi.toml` (national 13 / WH 11 / FI 24 / WIFI 3; west carved out; national `extra_supports` NE+NY, FL alone, MS confined, CA contact cap 4; WIFI δ = 1.0 fixed blocks). Main-map total K must be 48–54 (`MAIN_K`, score.py:91).
- **Dollars/bands**: `tools/looks/score.py:87–95` still codes the pre-D3 rules (`BAND` ±15% around τ, `DOLLAR_BAND` ±10% channel average) with `TARGET`{national 1.25B, WH 1.0B, FI 0.9B, IFA 1.25B} and per-fine-channel `DOLLARS` rates (ifa 62.14B); an IFA-only run special-cases dollars to `DOLLARS["ifa"]/k` (score.py:381). `merge.py:59–60` hardcodes IFA's `DOLLARS_PER_M_REL 1.2519681558` and `BAND_M (1000, 1437.5)` $M; `--window` is in m_rel. D3/E2/E3 bands ($1,062.5–1,437.5M national, $850–1,150M WH, $765–1,035M FI, WIFI ±15% of its mean) are owner policy only until #130's scorer change. Extract fields are identical (fine `current_channel`, `model_channel`, `m_rel`); canonical/channel→bundle tables in `export_long.py` (~line 13).
- **Structure**: IFA is one channel over all states, so state sealing (`--states`) partitions CONUS cleanly; the main map is four channels over the same 41 non-west states, so state-keyed region merges do not transfer as-is.
