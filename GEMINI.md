# User Preferences and Invariants

## GitHub Web Links Required
Always provide direct, clickable GitHub web links (`https://github.com/helios1168/td/...`) in responses for:
- Commits: `https://github.com/helios1168/td/commit/<hash>`
- Branches: `https://github.com/helios1168/td/tree/<branch>`
- Generated / modified maps: `https://github.com/helios1168/td/blob/<branch>/figures/<map_name>.png`
- Exported datasets: `https://github.com/helios1168/td/blob/<branch>/<file>.csv`
- Modified source code files: `https://github.com/helios1168/td/blob/<branch>/<path>`

Never rely solely on local `file://` links when sharing artifacts, maps, datasets, or code changes with the user. Always include the direct GitHub links.
