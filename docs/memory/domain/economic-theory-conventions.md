# Conventions for any economic-theory domain work on td

`docs/foundations/DOMAIN_economic-theory.md` is frozen (read-only since 2026-09-07); any new
domain plan is written elsewhere and supersedes it only by stating so. These conventions keep
cross-references intact.

- **Preserve section numbering.** `BRIEF.md`, `units/U1-cert|U2-stab|U3-inv|U5-crit|U6-sel.md`
  and `LIT_economic-theory.md` cite by number: §2.1 EF1/PO, §2.2 EG/CEEI, §2.3 criterion,
  §2.4 stability, §2.5 cooperative game, §2.6 the 98 as claimants, §2.7 strategy-proofness,
  §3's five statements, §4 steps with D1 to D5, §5 N1 to N6, §7 hand-offs, §8 Q1 to Q8. Append
  new material (§2.8+, N7+, D6+, Q9+); never renumber.
- **Two citation pools in different files.** `~/resources/economic-theory/FOUNDATIONS.md`
  (95 entries, cited in **bold**) and `docs/foundations/LIT_economic-theory.{md,bib}`
  (46 entries, cited in `code`). `fotakis2014` is in neither: it lives in
  `literature/RESEARCH_ADDITIONS.bib` and is withdrawn as a basis for ★8.
- `LIT_economic-theory.md` is inherited unchanged across tracks; a new literature run appends a
  dated section, never rewrites.

General `/domain` conventions: `mem:domain/lens-workflow`. Verdicts already reached:
`mem:domain/economic-theory-verdicts`.
