## Adopted formulation: carve-first (round 3)

**A, #103: the bound and the requests.** The support master, in dollars, with:

- n_S integer;
- coverage Σ_S t_{v,S} = 1;
- the band L·n_S ≤ Σ_v M_v t_{v,S} ≤ U·n_S;
- η floors, corridor floors and Σ n_S = K;
- the split binary s_v with F2's link Σ_{S∋v} n_S ≤ 1 + (U_v − 1)·s_v;
- the rule C row (below).

It solves lexicographic passes at gap 0, pinning each result before the next:

1. minimise Σ s_v, giving s*;
2. pin the count Σ s_v = s* (not the set) and minimise cuts;
3. pin the cuts and minimise diameter.

The certificate is a proof that Σ s ≤ s* − 1 is infeasible; a timeout is unknown. It runs **stage
0 first**: the rule-C arithmetic screen in code, extending `tools/exp/split_floor.py`.

- For each state over U: do its whole neighbours have room for the attach mass its pieces need?
- For each state under L: can its neighbours bring it into the band?

A also owns one dollar adapter, used by every lane. Its plans become carve requests, and
`--exclude` keeps the exact holder no-good encoding, used only to enumerate further plans.

**B, #129: the pattern generator.** A request is (σ, k, attach sets A_i, windows). B returns up
to 3 patterns, each a full partition of σ's ZCTAs, where every piece_i ∪ A_i:

- passes the exact M1 gate;
- lies inside [L, U];
- holds at least η·M_σ;
- is a support in 𝒮_c.

The search is heuristic, judged by the gate. The exact MILP and MODEL §4.10 are off the critical
path.

**P, #130: the library and the selection MILP.**

The library:

- whole-state columns g, each gated once as in #127;
- patterns p;
- seeds from the shortlist's M1-passing districts, re-weighted in dollars. FI 20 starts at
  s_drawn ≤ 6 from `set125/fi20_fi_nonc-r1`, against a forced floor of 5.

The MILP:

- **Coverage,** for each (channel, state) v: Σ_{g∋v} x_g + Σ_{p: v∈σ(p)∪A(p)} y_p = 1.
- **K as a range:** IFA 46–55, or 48 ≤ Σ_c K_c ≤ 54 on the main map, in one joint MILP.
- **Lexicographic passes** on the scorer's rank key, in order: splits Σ y_p, cuts Σ(k_p − 1)y_p,
  defects, extent, states per district, worst deviation, mean deviation (weighted by district).

The map is M1-clean with no repair. The final audit is an integration check, and a failure there
is a bug.

**Certificate.** If s_drawn = s_lower, the report says "matches the certified lower bound over
[A's domain]", never "minimal". This holds only when every column lies inside A's domain: family
supports, η-floored pieces, the same dollars and the same rule C. A restricted library proves
nothing about infeasibility.

**Dropped from v2:** cuts.json, support_ban, holder_nogood as a cut, and the plan, carve, cut,
re-plan loop. Of the R1–R13 changes in `CONSOLIDATED.md` round 2, R3, R4 and R6 are dropped; the

## Rule C
A district may hold whole states only, a piece of one split state, or a piece of one split state
plus whole states. For every support with |S| ≥ 2:

  Σ_{v∈S} s_v + |S|·n_S ≤ |S| + 1

| n_S | The row becomes | Meaning |
|---|---|---|
| 0 | vacuous | |
| 1 | Σ s_v ≤ 1 | at most one split state |
| ≥ 2 | infeasible | a multi-state support used twice would split every one of its states |

- It is valid only with F2's links kept.
- A spurious s_v = 1 cannot survive at the optimum, because setting it to 0 loosens every row and
  lowers the objective.
- A v1 bug: rule C written as a filter on the support family removes every multi-state support,
  so it must be a row.
- Rule C lives in **two places that must match**: this row, which gives s_lower, and the
  pattern structure in the library (one root; attach states whole and covered once).
