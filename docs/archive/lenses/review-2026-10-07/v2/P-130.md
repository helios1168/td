## Goal
Maps in which every district passes M1, with the fewest state splits A can certify under rule C:
plan, carve each split state, assemble a full ledger, audit, and feed back only exact cuts.

The pipeline ends with an eligible map, or with each requirement named as failed or unknown.
This is part P (owner, 2026-10-07), built against contract v2 alongside #103 and #129.

## Plan
1. **The loop, in `tools/exp/contig/pipeline.py`.**
   1. Call `tools/expb2/plan.py`. Never fall back to `td.master`'s diameter plan.
   2. Write one carve job per split state and run them in parallel, at most 6 processes.
   3. Assemble the ledger: whole states by unit, split states from the carves, every fine-channel
      cell routed.
   4. Write a run folder in `run.py`'s format (`districts.csv`, `ledger.csv`, `run.json`,
      `manifest.json`).
   5. Run the exact M1 gate on every district, plus the full scorecard audit.
2. **Feedback** (contract v2):
   - **Proved-infeasible carve:** add an exact `holder_nogood`, then re-plan.
   - **Whole-unit district failing the gate:** add a `support_ban`.
   - **Piece proved undrawable alone:** add a `support_ban`.
   - **Carved district failing P's gate after B's `ok`:** an integration error. Stop and add no
     ban.
   - **`unknown`:** try the next plan in the pool. When the pool is exhausted, the channel ends as "no map found",
     reported to the owner; no policy ban (owner 2026-10-07, D4: "Add splits; no policy bans").
   - **Re-plans that add splits** are allowed and reported as s* + g (owner 2026-10-07, D5).
   - No state-pair bans, and no automatic widening of δ.
3. **Pool and ranking.**
   - Draw every plan in the pool and score each drawn map.
   - In `tools/looks/score.py`: add **cuts** to the rank key, second after splits (owner decision
     2, 2026-10-05, `docs/lenses/COUNCIL_2026-10-05.md:42`), and replace the two balance checks
     with the per-district target band (owner 2026-10-07, D3), each with a test. Rescoring the
     existing shortlist happens when this lands (owner: "Later, with #130").
   - Rank order: splits, cuts, defects, shape, worst deviation, mean deviation; the REVIEW
     exception stays.
   - Report small pieces per map; add no piece floor.
4. **Balance pass,** with the splits fixed:
   - #103's fixed-candidate LP supplies target shares;
   - recarve, keeping the last carve the gate passed;
   - accept a recarve only if the drawn rank improves;
   - a failed balance target is never a ban.
5. **Run order.**
   - **Round 1** (this lane): build and run toys against A's stub CLI and canned carve results.
   - **Round 2,** once #103 and #129 land:
     1. FI 20 end to end;
     2. IFA at the smallest K ≥ 50 that A's grid shows feasible at ±15% (owner, D1);
     3. the assembled main map: national 15 + WH 11 + FI 20 + WIFI 3 = 49. WIFI is whole states,
        with no carve.

   Each map:
   - is rendered with `tools/maps/render.py` and tracked (T1);
   - goes to tier P if it passes every tier-1 check, else to tier E only if it is M1-clean and
     fails only balance, else to tier 3.

   Report s_incumbent + g only where a certified bound covers the ledger's read-back. Otherwise
   write "not covered". Never write "minimal".

Band: every district within ±15% of its channel's $ target, planned and judged the same way (owner 2026-10-07, D2 and D3; WIFI, with no target, keeps ±15% of its average).

Lane: `worker-advised` on `claude-bridge/claude-sonnet-5-5:high`. The Sol advisor uses Anthropic's
advisor timing. Sol reviews. Round 1 is capped at 2 solver processes.
