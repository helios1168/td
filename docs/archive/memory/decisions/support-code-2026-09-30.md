# Choices made while building the support-master code (td#64–#72)

**Status:** accepted 2026-09-30, landed on `main` with #65 and #67–#72 (m5 wave, td orchestrator session 01a0f177, worker and reviewer forks). Workers and the orchestrator made these calls without asking unless marked; each was reviewed in its issue's wave. Facts: `facts/support-code-2026-09-30`.

**Context.** The 2026-09-30 wave implemented MODEL.md (td#64, verified by #65) as `spec`, `supports`, `master`, `realize`, `audit` and `output`, plus exporter v3 fixes (#61) and the #72 verification.

**Decision.**
- **Wave scope:** #64, #65 and #67–#73 only; #3, #59, #63 and #74–#77 counted as blockers, being data and catalog work. A `workflow-assistant` plan marked "failed" for making no edits was used, since the plan was complete.
- **#65 / MODEL.md:** a dropped zero-opportunity unit's cells are listed with no owner (§1, §8), since an owner would need the zero-unit share convention the verifier ruled out. The §8 one-owner statement is scoped to "a unit in V_c of a channel solved"; Claim 1(2) is unchanged; REFERENCES.md and UNKNOWNS.md unchanged. Free singleton copies of {v} take centres from deterministic opportunity-weighted k-means on v, because one shared centroid cannot separate the copies (supervisor approved).
- **#68 master:** highspy directly, not `scipy.optimize.milp`, which exposes neither `mip_abs_gap` nor the engine's model status (trap 15). C9 not built (optional, off by default). Float residuals within 1e-6 of a unit's share sum move onto its largest t_{v,S}; larger misses raise, because HiGHS's 1e-7 tolerance would make a strict stop fail every solve. Incumbents are checked at `FEAS_TOL` = 1e-6, τ-normalized. The η cap row is built for every unit, not only clipped singletons, since it is the proved implied cap (MODEL §3.2). The decoded point is built from (n, t) with unused columns at 0, not the raw incumbent. `ETA_MIN` is a literal. The zero-share stop runs after every row check, so a row breach is named first; its regression plants a plan and drops the η rows, because `build` now refuses η < 1e-4.
- **#68 bisection:** steps use `mip_rel_gap` = 1.0 and keep the objective (trap 19); the planning δ is probed first, then 0 or `delta_top` = max(K − 1, 1) + max μ_S/τ with tol 1e-4, because [0, 1] misses channels needing δ > 1; an unknown step stops and reports the bracket proven so far.
- **#70 audit:** gap agreement compares the implied bound in objective units against allowance(obj), since comparing relative gaps within 1e-9 rejects reports the exact rule accepts when |objective| < 1. Invalid or none reports keep printing their own gap.
- **#69 realize:** normalized by the mean positive ZIP mass, not the total (which would make each rhs about 1/n); an unflowed positive ZIP raises rather than going to the nearest centre, which would hide an LP defect and could break Claim 3. Lines were trimmed elsewhere to keep the 400-line cap rather than raising it.
- **#71 output:** ledger GEOIDs, not names; district names carry the channel prefix, collisions add the next CBSA then an ordinal by mass, and a district with no CBSA opportunity is `rural <state>`. A ZIP that isn't a graph vertex keeps its rows, is left out of the audit and is counted in `run.json`. Maps are point maps over 2025 state outlines; principal cities come from the 2025 CBSA title, not the 2023 OMB list (vintage trap). A channel naming a hook stops the run. Channels are distinct regardless of case (APFS), names are capped at 250 characters, the scenario name is checked only when it names the default run directory, and `draw_maps` takes the run directory as `root` so a symlinked `maps/` can't escape. District ids get no separate guard.
- **#61 / #72 A1 exporter:** the filler guard skips only the exporter's own field names at fixed positions; the allowlist test asserts equality with emitted keys, not a subset; regressions inject unknown keys through the CLI (monkeypatching `build` and `channels_doc`); nested keys under exempt fields are checked; `export/README.md` states the case- and Unicode-insensitive rule. A verified guard-contract breach was rated P1, not P0, because the CLI generates fixed keys only.
- **Wave gates:** workers did not run the configured gate in-stage, because the workflow runs it afterwards and an in-stage run would advance the branch and make the gate block with "no new commit".

**Alternatives rejected.** Named inline above with each choice.

**Consequences.**

- On the seed-0 sparse fixture the 51 scenario's free-unit channels are infeasible at δ 0.10 (smallest δ with μ_S: national 0.266, WH 0.181, FI 0.283; with national clipped, exact smallest 0.4956, WIFI 0.5945), because the heaviest ZIP reaches 0.07–0.23 τ (#68).
